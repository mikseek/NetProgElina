# NetProgElina

Практическая работа по дисциплине «Технологии и методы программирования».

## Задание
Разработка клиентов сетевых служб (daytime и echo) на языке C++ с использованием сокетов.

## Структура проекта

* **daytime/** — UDP-клиент для службы daytime (порт 13). 
  * Отправляет запрос на сервер и выводит полученное время.
  * Сборка: `make`
  * Запуск: `./daytime_client <IP-адрес_сервера>`

* **echo/** — TCP-клиент для службы echo (порт 7).
  * Устанавливает TCP-соединение, отправляет введенный текст и выводит ответ сервера.
  * Сборка: `make`
  * Запуск: `./echo_client <IP-адрес_сервера>`
