# NetProgElina

Практическая работа №3 по дисциплине «Технологии и методы программирования».

## Задание

Разработка сетевых программ на языке C++ с использованием сокетов и протоколов UDP и TCP.

## Структура проекта

### daytime/
UDP-клиент сетевой службы Daytime (порт 13).

Получает текущее время с удалённого сервера.

Сборка:
`make`

Запуск:
`./daytime_client 172.16.40.1`

### echo/
TCP-клиент и TCP-сервер сетевой службы Echo.

Клиент отправляет сообщения серверу и получает их обратно без изменений. Сервер принимает подключения и обрабатывает полученные сообщения.

Сборка:
`make`

Запуск сервера:
`./echo_server`

Запуск клиента для локальной проверки:
`./echo_client 127.0.0.1 44214`

Подключение к кафедральному серверу:
`./echo_client 172.16.40.1`

Для завершения работы клиента используется команда `q`.

## Проверка работы

UDP-клиент Daytime и TCP-клиент Echo протестированы на кафедральном сервере.

Дополнительно проверено локальное взаимодействие TCP-клиента и TCP-сервера через адрес 127.0.0.1 и порт 44214.
